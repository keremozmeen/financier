# core

Pure, tested TypeScript business logic. No React, no Dexie (enforced by ESLint).

- `finance/` — limits, utilization, statement periods, installment schedules (Phase 1–2)
- `subscriptions/` — Sub-Radar detection (Phase 4)
- `banks/` — known Turkish banks, their marks and colors, matched from a card's bank or name (D21)
- `insights/` — Kipp's rule-based insight engine (Phase 5)
- `kipp/` — Turkish/English query parser (Phase 5)
